# oh-my-lsp CLI

`commander.js` 기반 TypeScript CLI 기본 스캐폴딩입니다.

## 시작하기

```bash
npm install
```

## 개발 실행

```bash
npm run dev -- hello
npm run dev -- hello --name Youngjin
```

## 빌드 / 실행

```bash
npm run build
npm run start -- hello
```

## 전역 링크(선택)

```bash
npm link
oh-my-lsp hello --name Youngjin
```
